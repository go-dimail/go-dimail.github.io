go-dimail is a pure-Go (no cgo) client for the Dimail API, the mail-hosting management API of the French government's La Suite numérique platform. The typed models and request methods are generated from the API's own OpenAPI document (committed in the repo) by an in-tree generator, so the whole surface — 96 models and 91 methods across users, domains, mailboxes, aliases, forwards, identities and the admin endpoints — stays faithful to the spec and regenerates with go generate ./.... The hand-written runtime adds Basic→bearer authentication, an HTTP transport, and a typed APIError. 100% test coverage, race-clean, CI green across 6 architectures.

Generated from source for reproducibility: the OpenAPI document and the generator both live in the tree, and CI fails if the checked-in generated code drifts from the spec. The client is CGO-free, so it cross-compiles and embeds anywhere. Its Ruby-idiomatic face — a Hash-returning Session bound by rbgo as require "dimail" — lives in the sibling org go-ruby-dimail.
